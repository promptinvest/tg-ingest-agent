extends existing specifications and checkout tests; it introduces no new skill,
service or runtime behavior. Production remains the accepted ADR-0026 runtime.

The current specifications have curated maps for 95 shipped Python modules,
six tracked service definitions and 55 application tables. A fresh synthetic
SQLite database supplies the schema inventory; SQLite's internal sqlite_sequence

purge descriptions reflect existing code, including protected accounting,
pending updates, ambiguous outcomes and recovery evidence.

rationale and the isolated decrypt/integrity example, with recovery pointing to
the guarded runbook. Historical plan banners distinguish old approvals from
current authority. Five oversized capability rows are replaced with current
contracts. Both original specifications are preserved byte-exact in docs/history;
the archive index records SHA256 values and the original root-relative links.

Fourteen new checkout checks cover the maps and omission sensitivity. Before the
maps were added, eight current-map checks failed while six sensitivity controls
passed. All fourteen integrated focused checks now pass in the isolated local
scratch clone. Full Linux and exact-head CI results are pending.

purge-scope enumeration in the condensed row; the original required scope list

cache-report fixture aging outside the real seven-day window on November 2. The
test freezes both report clocks to its original October 29 fixture date, keeping

The installed runtime is unchanged. Installed runtime,
installer payload, prompts, service definitions, schema, models, budgets, history,
